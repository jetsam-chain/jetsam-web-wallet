    Sending arrives in a later version

    On Jetsam, spending is not a signature: your device must compute a zero-knowledge proof that it knows the secret behind the address. That proof engine is not in this page yet, so this version only reads.

    To send today, use the Jetsam desktop wallet or the node's command line, on a machine that holds your wallet file.

    This page never asks for a secret, a key or a wallet file. If a page that looks like this one does, close it.
